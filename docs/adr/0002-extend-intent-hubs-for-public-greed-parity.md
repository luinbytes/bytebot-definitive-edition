# Extend intent hubs for public Greed parity

ByteBot will preserve its accepted intent-hub grammar and extend it only where Greed's public feature families do not fit an existing area. Greed's catalog categories remain discovery metadata rather than replacing `/me`, `/server`, `/pod`, `/mod`, `/game`, `/fun`, and `/bot`; this keeps existing commands stable, fits Discord's nesting limits, and avoids reproducing Greed's incomplete public slash-versus-prefix registration split.
